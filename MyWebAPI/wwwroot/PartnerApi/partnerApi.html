PATCH https://sandbox.nmi.com/api/v4/merchants/{gateway_id}

Update Merchant

Assign a fee schedule, send the welcome email, and agree to TOS/fees for a merchant — all in a single PATCH request.

Flexible Request: Toggle each section on or off. Only enabled sections are included in the PATCH body — run one step at a time or all at once. Pull the agreementTextId via GET /merchants/{id}/agreement_text.
Request Parameters
Path Parameter
The merchant ID that the request should operate on
ID of the fee schedule to assign
Pull via GET /merchants/{id}/agreement_text
Equivalent of "activate pending services immediately" in Partner Portal
API Response

Click "Update Merchant" to see the API response
