V5 checkout with 3DS

Collect.js tokenizes the card, Gateway.js runs payer authentication, then the app calls the NMI V5 sale through /api/v5/proxy. Use a public tokenization key for Collect.js and a public Checkout key for Gateway.js (see Gateway.js — keys are created under Merchant Portal → Settings → Security Keys). Those public keys may be the same or different depending on your setup. The V5 private API key is held server-side and is never exposed to the browser.
